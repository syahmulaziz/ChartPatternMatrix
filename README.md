# ChartPatternMatrix
TradingView Pine Script v6 multi-timeframe chart pattern detector with pattern scoring, confirmation states, and 3-TF confluence analysis.

MTF Pattern Matrix is a TradingView Pine Script v6 indicator that detects major chart patterns across three user-selected timeframes and combines them into a multi-timeframe confluence view.
The indicator is designed to help traders quickly understand whether price structure across multiple timeframes is bullish, bearish, neutral, forming, or confirmed, without constantly switching charts.
It currently supports patterns such as Double Top/Bottom, Head & Shoulders, Inverse Head & Shoulders, Triangles, Wedges, Flags, Pennants, Rectangles, and Rising/Falling Channels.
Key features include:
- 3 selectable analysis timeframes
- Multi-timeframe pattern detection
- Bullish and bearish bias classification
- Forming vs confirmed pattern states
- Pattern quality scoring
- 2/3 and 3/3 timeframe confluence detection
- Conflict detection when timeframes disagree
- On-chart MTF signal markers
- Compact pattern dashboard
- Optional confluence background highlighting
- Confirmed higher-timeframe candle mode to reduce repainting
- Alert conditions for bullish and bearish MTF confluence
Example usage:
View an M5 chart while simultaneously analysing M5, M30, and H4 chart structures.

The goal of the project is to create a clean, objective multi-timeframe price-action scanner that can later be expanded with pattern geometry, breakout levels, invalidation levels, targets, and additional confluence filters.
